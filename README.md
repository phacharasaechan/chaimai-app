# ChaiMai (ใช่ไหม)

เครื่องมือตรวจสอบว่า **ราคาและสเปกที่โฆษณา "สมเหตุสมผลหรือไม่"** เพื่อช่วยป้องกันการซื้อแฟลชไดรฟ์และพาวเวอร์แบงก์ปลอมหรือสเปกเกินจริง

เว็บไซต์: https://chaimai.app (ยังไม่ออกตัว)

> โครงการนี้ทำขึ้นเพื่อการเรียน ผลลัพธ์เป็นเพียงการประเมินความน่าสงสัย ไม่ใช่การพิสูจน์ว่าสินค้าเป็นของปลอม

---

## ChaiMai ทำอะไรได้

ผู้ใช้กรอก **ราคา** และ **สเปกที่โฆษณา** ของสินค้า แล้วระบบจะให้ผลเป็นระดับความน่าเชื่อถือพร้อมเหตุผล

| ผลลัพธ์ | ความหมาย |
|---|---|
| สมเหตุสมผล | ราคาและสเปกอยู่ในช่วงที่พบได้จริง |
| น่าสงสัย | บางค่าผิดปกติ ควรตรวจสอบเพิ่มก่อนซื้อ |
| น่าจะปลอมมาก | ค่าที่โฆษณาเป็นไปได้ยากในทางกายภาพหรือทางราคา |

### สินค้าที่รองรับ

**พาวเวอร์แบงก์** (กรอก: ราคา, ความจุ mAh, น้ำหนัก, กำลังไฟขาออก)
- น้ำหนักเทียบกับความจุ: เซลล์แบตเตอรี่จริงมีน้ำหนักขั้นต่ำตามความจุ
- ความจุเทียบกับเกณฑ์ของสายการบิน: พลังงาน (Wh) = mAh × 3.7 ÷ 1,000 โดยทั่วไปสายการบินจำกัดที่ 100 Wh (ประมาณ 27,000 mAh)
- ราคาต่อ mAh เทียบกับช่วงราคาของแบรนด์จริง

**แฟลชไดรฟ์** (กรอก: ราคา, ความจุ GB/TB, ความเร็วที่โฆษณา)
- ราคาต่อ GB เทียบกับช่วงราคาตลาด
- ความเร็วที่โฆษณาเทียบกับระดับราคา

---

## ความเห็นที่สองจาก AI

นอกจากผลจากกฎคำนวณ ผู้ใช้ขอ **ความเห็นที่สองจาก AI** ได้ ใช้ Groq  API

- ผลจากกฎคำนวณจะแสดงเสมอ ความเห็นจาก AI เป็นส่วนเสริม
- ระบบจะแสดงข้อความว่าบริการกำลังใช้งานหนักและให้ลองใหม่ภายหลังถ้าระบบมีการใช้งานหนัก
- ความเห็นจาก AI อาจผิดพลาดได้ ไม่ควรใช้แทนผลจากกฎคำนวณ
- มีการแคชคำตอบสำหรับข้อมูลที่กรอกซ้ำ เพื่อประหยัดโควตา

---

## ข้อจำกัด

- ระบบบอกได้เพียงว่า "สมเหตุสมผล" หรือ "น่าสงสัย" ไม่สามารถยืนยันว่าสินค้าจริงหรือปลอมได้
- ค่าอ้างอิงด้านราคาและน้ำหนักเป็นค่าโดยประมาณจากรายการสินค้าจริง และราคาตลาดเปลี่ยนแปลงได้ ควรอัปเดตตารางข้อมูลเป็นระยะ
- หลังซื้อแฟลชไดรฟ์ แนะนำให้ทดสอบความจุจริงด้วยโปรแกรมอย่าง H2testw (Windows) หรือ F3 (macOS/Linux)
- ยังไม่รองรับสินค้าประเภทอื่นนอกจากพาวเวอร์แบงก์และแฟลชไดรฟ์

---

## การตั้งค่าความเห็นที่สองจาก AI

**ห้ามใส่ API key ของ Groq ไว้ในโค้ดฝั่งผู้ใช้ (หน้าเว็บ)** เพราะใครก็เปิดดูและนำไปใช้จนโควตาหมดได้

ให้เรียก Groq ผ่านพร็อกซีเล็ก ๆ (เช่น Cloudflare Worker) และเก็บคีย์เป็นตัวแปรลับที่นั่น

```
GROQ_API_KEY=ใส่คีย์ของคุณที่นี่   # ตั้งเป็น secret บนพร็อกซี ไม่ commit ลง GitHub
```

เพิ่ม `.env` ลงใน `.gitignore` เสมอ

## การเผยแพร่ (Deploy)

1. push โค้ดขึ้น GitHub
2. เชื่อม repository กับ Cloudflare Pages
3. ตั้งค่าคำสั่ง build และโฟลเดอร์ผลลัพธ์ให้ตรงกับเฟรมเวิร์ก
4. เชื่อมโดเมน
